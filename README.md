#  Sales Dashboard – Power BI Project

##  Project Overview

This project is an interactive **Sales Dashboard** built using **Power BI** to analyze business performance across different dimensions such as product categories, regions, customer segments, and time.

The dashboard provides clear insights into **sales trends, profit analysis, and order-level details**, helping stakeholders make data-driven decisions.

---

##  Key Features

###  1. Sales Overview

* Total Sales: **563K**
* Total Profit: **244K**
* Quantity Sold: **2K**
* Sales breakdown by:

  * Product Category (Clothing, Food, Electronics, Furniture)
  * Region (East, West, North, South)
  * Customer Segment (Online, Retail, Wholesale)
* Time-based sales trend analysis

---

###  2. Profit & Performance Analysis

* Region-wise profit contribution (Waterfall Chart)
* Sales vs Profit comparison (Scatter Plot)
* Category-wise performance (Treemap)
* Region and category matrix for detailed comparison

---

###  3. Detailed Order Breakdown

* Transaction-level data including:

  * Date, Region, Product Category
  * Product Name, Customer Segment
  * Quantity, Sales, Revenue, Profit
  * Discount Percentage
* Helps in deep-dive analysis and identifying patterns

---

##  Tools & Technologies Used

* **Power BI** – Data visualization & dashboard creation
* **Microsoft Excel / CSV** – Data source
* **Data Modeling** – Relationships & measures
* **DAX (Data Analysis Expressions)** – Calculations and KPIs

---

##  Dashboard Insights

* **Clothing** category generates the highest sales
* **East region** contributes the most revenue
* Balanced contribution from **Online, Retail, and Wholesale segments**
* Sales show fluctuations but maintain an overall steady trend
